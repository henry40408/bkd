          Import and export

          Import

          Choose a bookmarks file exported from Chrome, Firefox, Safari, Pocket or Raindrop (an .html file). Folders become tags. A link you already saved is skipped.

          Export

          Download all of your bookmarks. Use HTML to move them to a browser or another service, and JSON as a plain backup.
